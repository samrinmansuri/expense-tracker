# expense-tracker

## Description

A simple command-line Expense Tracker built with Python that helps users record daily expenses, categorize spending, and monitor their remaining monthly budget.

This project demonstrates Python fundamentals such as object-oriented programming, file handling, loops, dictionaries, functions, and built-in modules.

---

## 📌 Features

* Add new expenses
* Categorize expenses
* Save expenses to a CSV file
* Read saved expenses automatically
* Display total spending by category
* Calculate total monthly spending
* Calculate remaining monthly budget
* Calculate remaining daily budget
* Color-coded budget output in the terminal

## 📊 Current Functionality

The application performs the following steps:

1. Takes expense details from the user.
2. Allows the user to choose an expense category.
3. Stores expense data in a CSV file.
4. Reads all stored expenses.
5. Groups expenses by category.
6. Calculates total spending.
7. Calculates remaining monthly budget.
8. Calculates daily spending limit for the remaining days of the month.
